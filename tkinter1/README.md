# Calculator program

 This is a simple, easy-to-use desktop calculator application built using Python and Tkinter. 
# what do
Clickable Buttons:It has a clean layout numbers (0-9), decimal points (.), a clear button (C), and math operations (+, -, *, /).
solve long equation: You can  click a long expression  and it will solve it sequentially from left to right.
Negative Numbers: it is solve the negative number.
Decimal Support: it is solve the decimal number.
For  Your Calculations: it is save the calculation what you are doing in the back side.

# How to use it:

1. firstly i installed python file.
2. Save the code provided in a file named `calculator.py`.
3. Open your terminal.
4. Run the following command to start your calculator:

```bash
python calculator.py
